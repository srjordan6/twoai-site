# Every crawler is welcome, on every page. This atlas exists to be read,
# cited, and ingested: the more models and search engines that carry its
# facts, the better it does its job. That explicitly includes the crawlers
# that build LLM training sets (Common Crawl, Google-Extended and the rest),
# not only the ones that cite live. Nothing here is gated.
#
# There is no Disallow for any agent on purpose. If a bot is ever blocked,
# it should be for hammering the origin, and that belongs at the edge
# (Cloudflare), not in a policy file that also turns away the crawlers we
# want. The sitemap and the machine-readable index below are the front door.
