# theworldofai.org is published by SRJ Consulting & Services LLC, Frisco,
# Texas. The site is static, rebuilt daily from a data pipeline; the only
# endpoints that accept input are /api/talent/* (account signup, profile
# submission, resume and photo upload) and /api/ask.
#
# Please report: authentication flaws in the talent portal, anything that
# exposes another person's profile or resume, injection through the ask
# endpoint, or a way to write to content this site publishes.
#
# Please do not report: missing security headers on static pages, the absence
# of rate limiting on public read-only JSON endpoints (/api/laws.json and its
# siblings are deliberately open and CORS-enabled for anyone to use), or
# automated scanner output without a demonstrated impact.
